# Changelog

## v0.1.0 (2026-10-11)
First tagged version.
- Pricing engine with formula-based products, safe evaluation and regulated tariff handling.
- Invoice reading in the browser (pdf.js and Tesseract.js OCR) with data extraction into simulations.
- Clients, consumption points, groups, simulations, contracts, commissions and spreadsheet import.
- PDF proposals (client and internal versions).
- Admin area with audit log, accounts, products, commission rules, market indices and tariffs.
- Redesign v3, password recovery and visibility, login preferences, fix for auth null tokens.
- 27 database migrations and 156 automated tests.

A full copy of the repository at this point is kept in the branch `backup/2026-10-11`.
